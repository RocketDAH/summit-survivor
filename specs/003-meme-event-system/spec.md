# Feature Specification: 밈 이벤트 시스템 (Meme Event System)

**Feature Branch**: `003-meme-event-system`

**Created**: 2026-06-06

**Status**: Draft

**Input**: 2지선다/콤보/버프 시스템 + 최신 밈 아이템으로 게임 재미 강화

---

## 핵심 컨셉

> "1.5초의 선택이 단순한 반사신경이 아닌, **전략적 딜레마**가 되도록"

### 변경 요약

| 기존 | 개선 |
|------|------|
| 아이템 1개 → 선택/무시 | 아이템 2개 → 하나만 선택 (양자택일) |
| 단순 HP 증감 | HP + 버프/디버프 + 특수효과 |
| 독립적 이벤트 | 콤보 연계로 효과 증폭 |
| 일반적인 등산 아이템 | 🔥 최신 밈/트렌드 아이템 |
| 최대 HP 100 | ** 시작 HP 100, 최대 HP 120** |
| 버프 아이콘만 표시 | **버프 로그 사이드바** (실시간 스크롤) |

---

## 1. 이벤트 시스템 개편

### 1.1 양자택일 이벤트 (2지선다)

**발생 조건**: 모든 이벤트가 2지선다로 변경

**규칙**:
- 1.5초 내에 왼쪽/오른쪽 중 하나 선택
- **선택하지 않으면 랜덤으로 하나 자동 선택** (운에 맡기기)
- 두 아이템은 서로 다른 "딜레마 유형"으로 구성

**자동 선택 규칙**:
- 시간 초과 시 50:50 확률로 왼쪽/오른쪽 중 하나 자동 적용
- 화면에 "⏰ 자동 선택!" 표시와 함께 어떤 아이템이 선택됐는지 보여줌
- 로그에는 `⏰ [아이템명] (자동)` 으로 기록
- 자동 선택된 아이템도 콤보에 반영됨

**딜레마 유형**:

| 유형 | 설명 | 예시 |
|------|------|------|
| 회복 vs 전진 | 체력 회복 vs 고도 부스트 | 정상 도시락 +25HP vs 암벽구간 -15HP +250m |
| 휴식 vs 장비 | 즉시 회복 vs 버프/보호 획득 | 쉼터 발견 +15HP vs 고어텍스 🛡️🌟20초 |
| 안전 vs 모험 | 확정 효과 vs 고위험고보상 | 바나나 +10HP vs 숏컷 ±30HP +300m |
| 보존 vs 돌파 | 체력 보존 vs 빠른 속도 | 텐트 설치 🧘10초 vs 스퍼트 -20HP +350m ⚡ |
| 자연 vs 인간 | 절경/날씨 vs 만남/동료 | 일출 +35HP 🌟 vs 산악회 선배 +20HP +100m |

### 1.2 특수 이벤트 (3지선다)

**발생 조건**: 고도 1000m, 2000m 도달 시 1회씩

**규칙**:
- 3개 선택지 중 하나 선택
- 선택 시간 3초 (중요한 결정)
- 게임 전체에 영향을 미치는 강력한 효과

## 2. 콤보 시스템

### 2.1 기본 규칙

**콤보 정의**: 같은 "카테고리" 아이템을 연속 선택

**카테고리 분류**:
| 카테고리 | 아이템 예시 | 콤보 효과 |
|----------|------------|----------|
| 🎒 보급품 | 삼각김밥, 초코바, 이온음료 | 회복량 증가 |
| ⛺ 휴식 | 쉼터, 산장, 텐트 | HP 보존 버프 |
| 🥾 장비 | 등산스틱, 아이젠, 고어텍스 | 속도/보호 버프 |
| 🌄 절경 | 일출, 운해, 정상뷰 | 특수 버프 (감동) |
| ⛈️ 날씨 | 폭풍, 안개, 낙뢰 | 환경 효과 |
| 🧗 도전 | 암벽, 급경사, 숏컷 | 고위험 고보상 |
| 📱 유혹 | SNS, 유튜브, 하산 충동 | 디버프/함정 |
| ⭐ 기적 | 헬기, 구조대, 신비로운 약초 | 레어 효과 |

### 2.2 콤보 보너스

| 콤보 수 | 보너스 | 표시 |
|---------|--------|------|
| 2연속 | 효과 +25% | 🔥 x2 |
| 3연속 | 효과 +50% | 🔥🔥 x3 |
| 4연속 | 효과 +100% | 🔥🔥🔥 x4 MAX |
| 5연속+ | 효과 +100% + 특수효과 | ⭐ COMBO MASTER |

**콤보 깨짐**: 다른 카테고리 선택 시 콤보 리셋

### 2.3 콤보 딜레마

이벤트 생성 시, AI가 의도적으로 콤보를 깨뜨리는 선택지 배치:

```
현재 콤보: 🍔 음식 x3 (다음 음식 +50%)

왼쪽: [🍔 치킨 +20HP] → 콤보 유지, 실제 +30HP
오른쪽: [💪 갓생모드] → 콤보 리셋, 하지만 30초 버프 획득
```

## 3. 버프/디버프 시스템

### 3.1 버프 종류

| 버프 | 효과 | 지속시간 | 아이콘 |
|------|------|----------|--------|
| 갓생모드 | HP 감소 속도 -50% | 30초 | 🌟 |
| 하이퍼 | 고도 상승 속도 +100% | 15초 | ⚡ |
| 철벽 | 부정 효과 무시 1회 | 1회성 | 🛡️ |
| 럭키 | 다음 랜덤 아이템 긍정 확정 | 1회성 | 🍀 |
| 광기 | 모든 효과 2배 (좋은것도 나쁜것도) | 20초 | 😈 |
| 존버 | HP 감소 완전 중지 | 5초 | 🧘 |

### 3.2 디버프 종류

| 디버프 | 효과 | 지속시간 | 아이콘 |
|--------|------|----------|--------|
| 멘붕 | HP 감소 속도 +50% | 15초 | 😵 |
| 슬로우 | 고도 상승 속도 -50% | 10초 | 🐌 |
| 혼란 | 아이템 효과 표시 안됨 | 다음 3회 | ❓ |
| 저주 | 모든 회복량 -50% | 20초 | 💀 |

### 3.3 버프 중첩 규칙

- 같은 버프: 지속시간만 갱신 (중첩 불가)
- 상반된 버프/디버프: 서로 상쇄
- 최대 동시 버프: 3개

```typescript
function generateEventPair(gameState: GameState): [Item, Item] {
  const { hp, altitude, currentCombo, activeBuffs, activeDebuffs } = gameState;
  
  // 1. 상황별 가중치 결정
  let scenario: ScenarioType;
  
  if (hp < 30) scenario = "crisis";           // 저HP: 회복 vs 역전
  else if (altitude > 2000) scenario = "sprint"; // 막판: 속도 vs 안전
  else if (activeDebuffs.length > 0) scenario = "rescue"; // 디버프: 해제 vs 무시
  else if (currentCombo >= 2) scenario = "combo"; // 콤보: 유지 vs 깨기
  else scenario = "normal"; // 기본: 다양한 딜레마
  
  // 2. 시나리오별 아이템 풀 선택
  const leftPool = getLeftPool(scenario);
  const rightPool = getRightPool(scenario, currentCombo);
  
  // 3. 딜레마가 되도록 페어링
  const left = weightedRandom(leftPool);
  const right = findDilemmaMatch(left, rightPool);
  
  return [left, right];
}
```

## 7. 밸런스 가이드라인

### 7.1 HP 경제

| 요소 | 수치 |
|------|------|
| **최대 HP** | **120** |
| **시작 HP** | **120** |

| 평균 이벤트 | 1.5초마다 |
| 2분간 이벤트 수 | ~80회 |
| 목표 클리어율 | 40-50% |

### 7.2 아이템 밸런스

- 긍정 효과 평균: +15 HP
- 부정 효과 평균: -15 HP  
- 랜덤 효과 범위: -60 ~ +60 HP
- 버프 가치: ~25 HP 상당
- HP 120 기준 여유 있는 시작, 하지만 2분 버티려면 전략 필요

### 7.3 콤보 밸런스

- 콤보 유지 시 평균 +50% 효율
- 콤보 깨짐 시 기회비용 ~10 HP
- 4콤보 이상은 어렵지만 달성 시 강력
